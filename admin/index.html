Pilih lagi untuk menambah slide. Atur urutan dengan ▲ ▼ — urutan di sini = urutan slide 1.jpg, 2.jpg, ... Poster tunggal cukup 1 gambar.
Biarkan halaman admin tetap terbuka (layar akan ditahan agar tidak mati). Jika Chrome tertutup/macet, buka lagi alamat panel yang sama — antrean lanjut otomatis tanpa memilih ulang file.
⚙️ Anti-limit & cadangan kuota
Tiap model Gemini punya kuota harian sendiri. Bila satu model habis, antrean langsung pindah ke model berikutnya — ini pengganti "obrolan baru" di aplikasi Gemini. Daftar model diambil otomatis dari Google (mengikuti versi terbaru), jadi kolom Model di ⚙️ Pengaturan AI sebaiknya dikosongkan.
Kuota dihitung per PROJECT Google, bukan per key. Buat key cadangan di project BARU (aistudio.google.com/apikey → Create API key → project baru); dua key dari project yang sama tidak menambah kuota. Key utama tetap di ⚙️ Pengaturan AI. Provider lain (Groq/OpenRouter/dll) ikut jadi cadangan terakhir bila kuncinya diisi & "Cadangan otomatis" dicentang.
