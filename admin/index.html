🖼 Buat Template Poster

Alur Kerja:
1. Isi data di bawah ini.
2. Klik "📋 Salin Template MD".
3. Buat folder baru di GitHub: posters/kategori-baru/nama-poster-001.
4. Upload gambar 1.jpg dan paste template ke poster.md. Commit.

📁 Struktur Folder

Agar website Anda membaca konten, struktur folder harus seperti ini:

posters/nama-kategori/nama-poster-001/
   ├─ 1.jpg
   ├─ 2.jpg (opsional)
   └─ poster.md

Isi file poster.md (Template):
---
judul: "Judul Poster"
sub_judul: "Sub Judul"
kategori: "Kategori"
tags: "tag1, tag2"
images: "1.jpg, 2.jpg"
tidakpakepdf: "brosur.pdf"
---
Isi caption di sini...

Salin teks di bawah, paste ke file poster.md di folder baru Anda.
